# javadev

Repositorio de prácticas, APIs REST, CRUDs y microservicios desarrollados con **Java** y **Spring Boot**, enfocados en arquitectura limpia, buenas prácticas y persistencia de datos.

## Estructura del Repositorio

| Carpeta | Descripción | Stack Principal | Estado |
| :--- | :--- | :--- | :--- |
| `accounts-apirest/` | API REST para gestión de cuentas y operaciones básicas aplicando separación por capas, validaciones y manejo de errores. | Java 17, Spring Boot, Maven | Disponible |
| `cruds_ejemplos/` | Ejercicios y ejemplos prácticos de operaciones CRUD y patrones habituales en desarrollo backend. | Java, Spring Boot | En progreso |
| `microservicios_apirest/` | Estructura y prácticas orientadas a servicios desacoplados y APIs REST. | Java, Spring Boot | En desarrollo |

## Competencias Clave
* **Backend:** Java (8–21), Spring Boot, APIs RESTful (JSON), validaciones y arquitectura por capas.
* **Bases de Datos:** PostgreSQL, MySQL, SQL Server.
* **Infraestructura y Herramientas:** Git, Docker, Linux, Maven.
